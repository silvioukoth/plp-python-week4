# Grades, Eligibility & Smart Decisions

This repository contains my PLP Python Week 4 assignment, which focuses on decision-making using `if`, `elif`, `else`, combined conditions, input validation, and nested decisions.

## Files

* `grade_classifier.py` — Validates a score and assigns a grade from A to F.
* `eligibility_checker.py` — Checks whether a person is eligible to join a coding club based on age and parental consent.
* `atm_menu.py` — Simulates an ATM withdrawal using a PIN check and nested balance decision.
* `screenshots/` — Contains screenshots showing the required program runs.

## When is `elif` better than several separate `if` statements?

`elif` is better when only one condition should be selected from several possible choices. It stops checking the remaining conditions after one condition is true, making the program clearer and more efficient.
